- `const` Member Functions
- Encapsulation
- Inheritance

  - Multiple

  - Hybrid
- Method Overriding
- `override` Keyword
- Virtual Functions
- Runtime Polymorphism

- Abstract Classes
- Virtual Destructors
- Friend Functions & Friend Classes
- Operator Overloading
